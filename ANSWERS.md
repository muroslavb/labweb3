# Відповіді на контрольні питання (ЛР3)

**1. Що таке компонент у Vue.js та яку роль він виконує?**
Компонент — самодостатній повторно використовуваний блок інтерфейсу, що поєднує розмітку, логіку та стилі. Застосунок — це дерево компонентів: великий UI розбивається на малі частини (`UserCard`, `Users`), які простіше підтримувати, тестувати й перевикористовувати.

**2. Що таке SFC? Які секції містить?**
Single File Component — файл `.vue`, що зберігає компонент в одному місці. Секції: `<template>` (розмітка), `<script>` / `<script setup lang="ts">` (логіка) і `<style>` (стилі, зокрема `scoped`).

**3. Що таке шаблон компонента та які конструкції в ньому можна використовувати?**
Шаблон — декларативний HTML-опис інтерфейсу, зв'язаний з даними компонента. Можна використовувати інтерполяцію `{{ }}`, JavaScript-вирази, директиви (`v-if`, `v-for`, `v-bind`, `v-on`, `v-model`, `v-show`), виклики методів і обчислюваних властивостей, використання інших компонентів.

**4. Різниця між звичайним HTML і шаблоном Vue?**
HTML статичний. Шаблон Vue — валідний HTML із розширеним синтаксисом: реактивні дані, директиви, події, компоненти. Vue компілює його у render-функції, які оновлюють DOM при зміні стану.

**5. Що таке директиви та їхній синтаксис?**
Директиви — спеціальні атрибути з префіксом `v-`, що додають шаблону реактивну поведінку. Синтаксис: `v-назва:аргумент.модифікатор="вираз"`, наприклад `v-on:click.prevent="save"`. Скорочення: `:` для `v-bind`, `@` для `v-on`.

**6. Для чого `v-bind`? Приклад.**
Для динамічного прив'язування атрибутів і пропсів до виразів: `<img :src="user.picture" :alt="altText">`, `:class="{ active: isActive }"`.

**7. Різниця між `v-bind:src="…"` та `:src="…"`?**
Жодної: `:` — скорочений запис `v-bind:`.

**8. `v-if`, `v-else-if`, `v-else`, `v-if` vs `v-show`.**
`v-if` рендерить елемент лише коли вираз істинний: інакше елемента немає в DOM (він створюється й знищується). `v-else-if` — додаткова умова в ланцюжку, `v-else` — гілка за замовчуванням; вони мають іти одразу після `v-if`/`v-else-if`. `v-show` завжди рендерить елемент і лише перемикає CSS `display: none`. `v-if` дорожчий при перемиканні, але дешевший на старті; `v-show` — навпаки, і не працює з `<template>` та `v-else`.

**9. Для чого `v-for`? Як використовувати `:key`?**
Для відображення списку на основі масиву/об'єкта/діапазону: `v-for="user in users"`. `:key` має бути унікальним і стабільним (наприклад, `user.id`), щоб Vue коректно перевикористовував і переміщував елементи при зміні списку. Не використовуйте індекс, якщо порядок може змінюватись, і не комбінуйте `v-for` з `v-if` на одному елементі.

**10. Що таке реактивність і як пов'язана зі зміною даних у шаблоні?**
Це механізм, за яким Vue відстежує використання реактивного стану (`ref`, `reactive`, `computed`) і при його зміні автоматично й ефективно перерендерює лише ті частини DOM, що від нього залежать. Тому достатньо змінити `genderFilter.value` — список оновиться сам.
